# Basic AI Tool for Writers — v3

**3.0.0-beta.2** — teste de integração para Obsidian (desktop e Android; teste real do aplicativo ainda necessário).

## O que mudou

O Basic AI mantém as funções de dicionário, IA, tradução, revisão LanguageTool, chat e projetos inspirados no Longform, e passa a oferecer uma barra lateral **Ferramentas de escrita** com três abas.

### Sugestões (inspiradas no Various Complements)

Autocomplete local a partir da nota atual, notas do cofre, dicionários personalizados, título de links internos e nomes de propriedades YAML. As fontes são independentes, desativáveis, e podem ser limitadas por arquivos, tamanho e pastas excluídas. O índice fica em memória (não é enviado para a rede) e é reconstruído conforme necessário. O painel oferece **Mostrar sugestões**, **Reindexar cofre** e **Abrir dicionário**.

As sugestões respeitam cabeçalhos YAML, trechos de código, wikilinks e variantes. A ordem é influenciada por frequência e escolhas anteriores, se habilitado. Arquivos de dicionário podem usar linhas com 'palavra => texto inserido'.

### Variantes (inspiradas no VariantEditor)

Sintaxe inline compatível: `{{original|alternativa 1|alternativa 2}}^0` (o número seleciona a alternativa ativa). Comandos para **Criar da seleção**, **Editar no cursor**, **Anterior/Próxima**, **Confirmar escolhida**, **Confirmar todas** e **Gerar com IA**. Alterações que afetam o texto podem disparar um snapshot antes, se habilitado.

A revisão gramatical inclui o botão **Criar variante**, preservando a formulação original. Ao gerar variantes por IA, o trecho selecionado é enviado ao provedor configurado somente após comando explícito.

### Versões (inspiradas no Note Snapshots)

Histórico separado por nota em `.basic-ai-history/`: snapshots manuais, opcionais automáticos após salvamento, snapshots nomeados, comparação de linhas, restauração com backup anterior, renomeação de notas, exclusão individual e captura opcional de anexos binários deduplicados por conteúdo.

Na restauração, **anexos existentes nunca são sobrescritos**, pois podem ser compartilhados entre notas. A opção de restauração de anexos recupera somente arquivos ausentes. Históricos do plugin Note Snapshots original em `.note-snapshots/` são preservados sem alteração, mas **não são importados automaticamente nem totalmente interoperáveis** com o novo armazenamento.

## Comandos

Abra a paleta do Obsidian e procure **Basic AI:**. Os principais comandos são: abrir ferramentas, mostrar/reindexar sugestões, ligar/desligar autocomplete, criar/editar/trocar/confirmar variantes, gerar alternativas por IA, salvar uma versão e abrir histórico.

O novo ícone da fita lateral abre as Ferramentas de escrita. Também existe um atalho na barra lateral principal do Basic AI. Os atalhos de teclado são configuráveis pelas preferências do próprio Obsidian.

## Configurações

Nas configurações do Basic AI há abas dedicadas **Sugestões**, **Variantes** e **Versões**. Pode desativar cada módulo independentemente. Os três módulos locais não enviam notas para a rede; provedores de IA, tradução e LanguageTool mantêm seus fluxos de rede atuais, quando solicitados.

Chaves de API continuam armazenadas nas configurações do plugin (`data.json`) sem criptografia adicional. Não compartilhe esse arquivo. A versão 3 cria `data.v2-backup.json` na pasta do plugin antes de migrar dados anteriores, quando o arquivo original existe.

## Atualização e retorno para a v2

1. Faça cópia de segurança do cofre e do diretório `.obsidian/plugins/basic-ai-tool-for-writers/`.
2. Instale os três arquivos do build (`main.js`, `manifest.json`, `styles.css`) na pasta do plugin.
3. Confira projetos Longform, configurações da IA, dicionários e revisão, de preferência em um cofre de teste.
4. Para retornar, reinstale os arquivos da v2 e, se necessário, restaure o `data.json` original salvo como `data.v2-backup.json`.

**Não remova os plugins originais nem os históricos antigos até confirmar seu fluxo de trabalho.** O autocomplete, variantes e snapshots novos são implementações próprias inspiradas nos plugins citados em [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md), não cópias integrais do código original. A v3 ainda não garante paridade integral com todos os modos e formatos de cada plugin upstream.

## Desenvolvimento e testes

A distribuição para Obsidian continua em `main.js`, gerada dos módulos `src/v3/` e do gerenciador `projects.js`.

```sh
npm run build
npm run check
```

`npm run check` executa verificação de sintaxe, sincronização dos arquivos gerados, testes do Longform e testes de integração da v3. A validação automatizada não substitui teste manual no Obsidian Android: verifique teclado aberto, touch, popups, snapshots de anexos, dark/light e cofres grandes antes de tratar a v3 como estável.

## Beta 2 — correções no Obsidian Mobile

- **LanguageTool/Markdown:** os delimitadores de itálico, negrito e texto riscado são mascarados sem alterar o comprimento do texto, mantendo as posições exatas dos erros. Sugestões que tocam na marcação são descartadas, mas o texto real continua sendo analisado.
- **Revisão:** o popup passa a medir seu conteúdo e respeitar a área visível, incluindo alterações de altura do teclado. Botões usam classes estáveis com largura adequada para celular.
- **Cenas:** os controles não ocupam mais uma linha por botão. Os comandos frequentes ficam nas setas ↑/↓, e as outras ações usam o menu contextual do Obsidian (`⋯`).
- **Testes:** regressões de Markdown e offsets; validação do código gerado, do esquema de versão e da inicialização do plugin.

A versão continua em beta até ser validada no Obsidian Android com diferentes tamanhos de tela e teclados.
