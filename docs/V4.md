# Basic AI Tool for Writers — v4 (4.0.0-beta.1)

The final integration series adds independently implemented tools inspired by community Obsidian plugins. Existing AI, LanguageTool, dictionary, translation, Longform projects, autocomplete, variants and version history remain available.

## New integrations

| Feature | Behavior | Settings |
|---|---|---|
| Abbreviations | Expands configured abbreviations when typing a space, with independent enable and case-sensitive controls. | Basic AI → Abbreviations |
| Another Name | Shows the string frontmatter property another-name immediately below the note title. | Basic AI → Secondary title |
| View Mode | Honors prefer-view: read, edit, edit-source and edit-preview frontmatter. | Basic AI → View mode |
| Homework | A fifth Tasks tab inside Longform projects: quick tasks, lists, groups, due dates, linked notes, completion tracking. | Basic AI → Tasks |
| Insta TOC | Foldable, automatically updated insta-toc Markdown code blocks based on Obsidian heading metadata. | Basic AI → Auto TOC |
| Unicode Search | Offline character picker, U+ hexadecimal insertion, favorites and recent characters. | Basic AI → Unicode |
| Template by Note Name | Apply a Markdown template with the same filename to a newly created empty note. | Basic AI → Templates |
| TTS | Device/browser speech synthesis with languages, voice selection, rate, pitch, volume, playback controls. | Basic AI → Speech reader |

## Details

### Abbreviations

Default entries from the provided Abbreviation plugin include eg., atm, imo, w/, w/o, ily, btw, afaik and rn. Each is editable, individually enabled and can be case-sensitive. Expansion occurs on typed space, not on paste.

### Longform tasks

Longform now has Scenes, Project, Compile, Notes and Tasks tabs. Tasks are grouped by subjects, each project has its own lists, and these entries never become part of the compiled manuscript. The original Homework Manager data are not imported automatically; this is a project-specific workflow.

### Insta TOC

Use the command Insert automatic table of contents. This inserts a code block beginning with three backticks and the label insta-toc, followed by the generated list and a closing three-backtick fence.

A rendered list is clickable and collapsible. Headings are sourced from the Obsidian metadata cache. Basic local YAML title, omission and levels options are recognized. Full parity with every advanced Insta TOC upstream option is not guaranteed.

### Unicode

Search for curated Unicode symbol names or insert an arbitrary valid scalar value, for example U+2764. The local named catalog is smaller than the complete Unicode Character Database available to the original Unicode Search plugin.

### Template by Note Name

Set a folder (for example Templates). When a new empty note is created, a matching same-named Markdown file from the template folder is applied. Variables: title, date and time, surrounded by double braces. Existing content is protected by default. No corresponding source file for Template by Note Name was included among the uploaded attachments: this behavior was independently implemented.

### TTS

Uses the system Web Speech API without an AI model. Google-named voices have priority if available on the device. Availability, pronunciation quality, offline behavior, and language support depend on Android, Electron, the browser and installed voices; system voice providers may access online speech services. This plugin itself does not call a separate TTS API.

Use the Writing Tools Speech reader tab or the commands to read the selection/note, pause, resume and stop.

## Interface language

General settings offer Auto, Português and English. New integrated tools have both languages; the previously mixed Longform, Writing Tools and settings labels have an expanded centralized English translation map. Please report overlooked strings.

## Backup and update

Before upgrading, back up the vault and plugin data. When migrating a v3 configuration, the plugin preserves settings and makes a data.v3-backup.json backup of the original file, if it exists. It does not remove the individual plugins or their data.

For manual installation, update main.js, manifest.json and styles.css together and reload Obsidian. To roll back, restore the previous files and saved configuration.

If original plugins remain active alongside integrated features, disable duplicate automatic triggers to prevent two abbreviation/template/TOC extensions from interfering.

## Development

Run npm run build to assemble the standalone distribution and npm run check to validate syntax, synchronized sources, migrations and behavior. Automated tests are not a substitute for manual desktop/Android checks, especially with virtual keyboards and device speech voices.
