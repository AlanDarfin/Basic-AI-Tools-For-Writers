# Basic AI Tool for Writers 4.3.1

## Fixed: typewriter current-line indicator

The active-line accent no longer overlaps the first character on desktop and mobile. The former inset shadow is replaced by a separate accent marker, with consistent left-side spacing on all editor lines while Typewriter mode is enabled. The background highlight and current-line tracking remain unchanged.

No feature additions or other behavior changes. All remaining writing, cursor-memory and AI features are preserved.

- Obsidian 1.11.4 or newer; desktop and mobile.
- Version metadata and English/Portuguese documentation refreshed.
- Regression test for line-marker separation, full suite and CSS-lint validation.
- Release tag: `4.3.1`, without a leading `v`.
