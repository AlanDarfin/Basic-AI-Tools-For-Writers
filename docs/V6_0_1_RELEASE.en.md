# Basic AI Tool for Writers — 6.0.1

**Stable maintenance release.** This update refines the Longform project's scene tree without changing the book structure or editing behavior.

## Changes

- Replaced the subchapter arrow badge with one unobtrusive vertical guide for each nesting level: chapter (no guide), subchapter (one), nested note (two), etc.
- Reduced nesting offset to keep long chapter titles readable in narrow Android panes. The drag handle and reorder actions remain aligned.
- Kept accessible chapter names and levels via the existing screen-reader labels.
- Updated English and Brazilian Portuguese release documentation, metadata, and regression coverage.

No manual or automatic chapter navigation behavior was changed.

## Install

Update `main.js`, `manifest.json` and `styles.css` in `.obsidian/plugins/basic-ai-tool-for-writers/`, or extract the release ZIP. Restart or reload the Obsidian plugin. Requires Obsidian 1.11.4 or newer.
