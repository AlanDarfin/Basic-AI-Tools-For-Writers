# Basic AI Tool for Writers — 6.0.0-beta.3

**Beta experimental**; a versão estável continua sendo **5.2.0**.

- Navegação Longform agora consulta o YAML real do índice quando o cache de metadados não fornece as cenas. Mantém a ordem de capítulos e subcapítulos.
- Ruby renderizado no Live Preview, com texto de origem disponível ao selecionar a anotação.
- Novo Ruby abaixo com `{texto|leitura|under}`; o formato antigo `{texto|leitura}` continua acima.
- Configurações Markdown e navegação Longform mais compactas para telas pequenas.
- Testes de regressão para projetos e renderização Ruby.

Para instalar: substitua `main.js`, `manifest.json` e `styles.css` no diretório do plugin e recarregue o Obsidian. Testar no Android antes da versão final.
