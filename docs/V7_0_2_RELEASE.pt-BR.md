# 7.0.2 — Barras laterais mais compactas no computador

Correção visual pontual nas barras de ferramentas de escrita e Longform/projetos.

- Corrigido o campo de pesquisa de Definições e a caixa de contexto que cresciam demais na vertical devido às regras de flex de campos dentro de um painel vertical.
- Reduzidos levemente o preenchimento, a altura das abas e controles e os espaçamentos de botões **somente no desktop**, para aproveitar melhor resoluções como 1440×810.
- Mantida a rolagem horizontal das abas, assim como o tamanho legível das fontes.
- Sem alterações ao tamanho dos controles no Android, Pandoc, dados ou ferramentas de escrita.
- Sem `zoom` no CSS, transformações de escala ou mudanças globais de tema do Obsidian.

A alteração em execução é somente visual no `styles.css`. Atualize `main.js`, `manifest.json` e `styles.css` juntos usando a release oficial.
