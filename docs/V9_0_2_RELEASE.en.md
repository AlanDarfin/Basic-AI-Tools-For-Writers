# Basic AI Tool for Writers 9.0.2

**Visual maintenance update · Obsidian 1.11.4+ · Desktop and Android**

## Homepage

- **Heading and icon above the search:** the customizable title is once again the first element, retaining theme accent or separate color preferences.
- **Full-width search immediately below the heading:** retains full vault paths, highlighted results and **Up**, **Down**, **Enter**, **Escape** keyboard controls from 9.0.1.
- **Evenly distributed shortcuts:** six buttons in one row in wide panels, a balanced 3 × 2 grid in medium panels, and 2 × 3 in narrow panels. Responsive rules use the homepage panel's actual width rather than only the application window width.
- **Calendar and cards preserved:** configurable cards below the shortcuts remain unchanged.

Vault notes, Spaces settings and the plugin identifier are unchanged.

## Update

Back up `.obsidian/plugins/basic-ai-tool-for-writers/data.json`. Replace `main.js`, `manifest.json` and `styles.css` with the **9.0.2** release files, then reload the plugin.

Automated checks cover element order, responsive layout rules, search controls, source/bundle alignment and CSS validation. A quick visual check in your Obsidian installation is recommended.
