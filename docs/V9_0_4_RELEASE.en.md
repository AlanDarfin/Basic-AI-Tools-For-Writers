# Basic AI Tool for Writers 9.0.4

**Mobile calendar visual fix · Obsidian 1.11.4+ · Desktop and Android**

## Mobile calendar

- **No circles or pills:** day numbers no longer sit inside rounded backgrounds.
- **Top-left day numbers:** leave more of each cell available to display events.
- **Full accent-colored current day:** the entire current-day tile uses the Obsidian theme's **accent color** with contrasting text.
- **Events preserved:** date and event interactions remain available.
- **Responsive behavior:** styling applies both on narrow viewports and on Obsidian mobile, including tablets.

Desktop calendar styling, event recurrence and editing behavior are unchanged.

## Update

Back up `.obsidian/plugins/basic-ai-tool-for-writers/data.json`. Download `main.js`, `manifest.json` and `styles.css` from release **9.0.4**, replace the files inside the plugin folder, then reload Obsidian.

Automated tests cover mobile tile styling, full-cell accent highlights and retained event rendering. A visual check on your device and theme is recommended.
