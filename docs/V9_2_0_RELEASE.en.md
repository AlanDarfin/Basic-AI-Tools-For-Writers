# Basic AI Tool for Writers 9.2.0

## Favorites and file previews
- Homepage favorites now share customizable filled icons with the native File Explorer.
- Folder descriptions read from the folder note's `description` YAML property.
- Preview modes: off, folder notes only, all Markdown notes plus folder notes.
- Configurable description property and length.

## Writing and widgets
- Independent `columns`, `progressbar`, `widgets` and `meta-field` blocks.
- Markdown columns, manual/date progress, clocks, quotes, countdowns and counters.
- Safe YAML property fields: toggle, text, number, select and read-only view.
- Not complete Meta Bind or Multi-Column Markdown replacements.

## Research, reading and sessions
- Quote widget optionally displays explicitly identified highlights from local Markdown Zotero imports, with a link to the original note.
- Local Zotero integration only; no Zotero API, Better BibTeX or direct PDF import.
- Scoped reading typography, line height, width and heading colors.
- In-memory session drafts with explicit save; no automatic deletion of vault files.

## Compatibility
Independently written functionality inspired by nine projects credited in THIRD_PARTY_NOTICES.md. No GPL source was copied. Advanced upstream functionality remains available through the original plugins. Regression tests added.
