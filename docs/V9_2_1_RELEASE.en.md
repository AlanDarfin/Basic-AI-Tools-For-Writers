# Basic AI Tool for Writers 9.2.1

## File Explorer
- Favorites are aligned at the far right of note rows, in the position used by the Folder Notes open-book button in folder rows.
- Customizable icons: outlined when not favored (hover/focus, touch-accessible on mobile) and filled when favorited.
- The Folder Notes open-book button remains available.
- Favoriting notes from the homepage updates the explorer.

## File and image previews
- More readable descriptions with a configurable one-to-four-line clamp, without overlapping action buttons.
- Local image thumbnails from the first embedded image or YAML `cover`, `image`, `thumbnail`, or `banner` fields.
- Adjustable thumbnail size.
- In **All notes + folder notes** mode, a Markdown body excerpt is shown if no YAML description exists.
- New native File Explorer toolbar toggle to show/hide previews; placed along the bottom on mobile.
- Visibility is independent of the configured folder-only/all-notes scope.

## Compatibility
Independent original code with no copied third-party plugin implementation. CI verification does not replace real-device visual testing on desktop and Android.
