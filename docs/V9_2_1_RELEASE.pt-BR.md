# Basic AI Tool for Writers 9.2.1

## Explorador de arquivos
- Favoritos agora aparecem alinhados à direita das notas, na mesma posição horizontal usada pelo botão de abrir Folder Notes nas pastas.
- Ícones personalizáveis: contorno quando não favoritado (ao passar o mouse/receber foco; visível ao toque no mobile) e preenchimento ao favoritar.
- O botão de abrir Folder Notes continua disponível nas linhas de pasta.
- Alterações feitas na lista de favoritos da homepage são refletidas no explorador.

## Prévia de arquivos e imagens
- Descrições mais legíveis, em até quatro linhas configuráveis, sem o texto esbarrar nos controles.
- Miniaturas de imagens locais: primeira imagem incorporada à nota ou propriedades YAML `cover`, `image`, `thumbnail` e `banner`.
- Tamanho das miniaturas configurável.
- No modo **Todas as notas + folder notes**, quando não existe descrição YAML, uma prévia textual pode ser retirada do início da nota.
- Novo botão na barra nativa do explorador para mostrar/ocultar prévias instantaneamente, localizado na parte inferior na interface móvel.
- Controle independente de visibilidade: ocultar não altera a preferência de mostrar só Folder Notes ou todas as notas.

## Compatibilidade
Implementação original sem copiar código de plugins de terceiros. A validação automática não substitui um teste visual no Obsidian para desktop e Android.
