# Basic 13.8.0 verification / Verificação

Verified on 2026-11-12 using Node 22 and Obsidian 1.15.0 in isolated Linux/Electron vaults with synthetic notes.

## Automated checks / Verificações automatizadas

`npm run build`, `npm run check` and `node --test tests/css-community-lint.test.cjs` passed. The regression runner passed **154 test files**, including companion capabilities, editor context changes, native persistence, deferred views, voice ownership, task concurrency, mobile placement, LanguageTool cancellation and PRs #136–#138. Generated JavaScript, CSS, metadata and the settings search index are synchronized.

## Native companions / Plugins originais

All nine official releases loaded together: Ultimate Toolkit 2.9.17, Visual Kit 0.9.0, Snailkit 0.2.9, dropit 3.3.1, Syncthing Integration 2.4.0, Syncthing Manager 1.4.5, Obsidian Git 2.43.0, FIT 1.5.0 and LanguageTool 1.6.0.

- The connected-plugins center displayed nine cards and recovered through two Basic disable/enable cycles, including deferred view loading.
- Native Snailkit, Syncthing and Git panels opened. Visual Kit reused the existing HTML view with its file and opened its actual annotation dialog.
- Toolkit preferences used `saveSettings`; Visual Kit used `persist`, preserving its settings/index envelope and native ribbon updates.
- Basic routed only the selected synthetic passage through Toolkit's original playback methods. Pause, resume and stop retained session ownership. The audio scheduling boundary was stubbed.
- LanguageTool received the actual CodeMirror instance after restoring the correct note. Its remote checker was stubbed to inspect context without submitting text.
- The official FIT release lacked the source-head status command; the bridge omitted the unavailable action.

Todos os plugins oficiais foram carregados juntos. Painéis, persistência, recarregamento, seleção de texto e contexto do editor foram conferidos no aplicativo. Transportes de rede e processos externos foram bloqueados antes de ativar os plugins; nenhum servidor real, sincronização remota ou áudio audível foi exercitado. Rotinas automáticas dos plugins externos continuam sendo responsabilidade deles.

## Writing and homepage / Escrita e página inicial

Native keyboard events confirmed `--` → `–`, a third hyphen → `—`, and Backspace → the original `---`. Longform divider creation, captions, movement and independent variants passed. Homepage measurements at 1280×800, 412×915 and 1024×800 confirmed desktop centering, narrow/mobile stacking, centered SVG/custom image and long text without horizontal overflow. The final measurements used the regenerated CSS after restarting Obsidian.

Teclado, separadores, variantes, exportação e centralização da página inicial foram exercitados no Obsidian real. As capturas estão em [docs/images/13.8.0](../images/13.8.0/).

## Mobile scope / Escopo móvel

Narrow viewport and mobile CSS checks cover the interface and layout algorithm. Unit regressions separately exercise mobile platform gates and missing Git backends. Desktop Electron emulation does not establish physical Android/iOS compatibility; native mobile navigation, device keyboards and live remote services still require device-specific verification.

A emulação de viewport/CSS não substitui aparelho físico. Os testes não comprovam compatibilidade de navegação nativa, teclado de dispositivo ou serviços remotos no Android/iOS.

Native layout evidence: the connected center rendered nine cards without horizontal overflow; mobile CSS action buttons measured at least 44 px. Toolkit speech controls were checked at 412×915, 320×640 and a short 412×420 viewport. Snailkit's native phone sidebar showed its 58×58 task button and two tag-fan buttons; refreshing compatibility preserved the open fan anchor. The explorer priority was checked with computed styles for Toolkit, Basic and disabled compatibility, retaining both original icon nodes. Native checks found and fixed a CSS specificity conflict that initially left duplicate icons visible.

A central exibiu nove plugins sem overflow. O posicionamento foi conferido em janelas estreitas e curtas, com áreas de toque de 44 px. O botão de 58×58 do Snailkit e seu leque mantiveram as posições. As duas prioridades de ícone e a restauração ao desligar foram verificadas pelos estilos calculados, preservando os elementos originais. Veja [medições e limites](13.8.0-layout-qa.json).
