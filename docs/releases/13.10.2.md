# Basic 13.10.2 — Ajustes da navegação flutuante no celular

Requer **Obsidian 1.11.4 ou superior**.

- A faixa de status fica separada, abaixo da navegação flutuante. Os indicadores mais longos podem ser deslizados para o lado.
- A homepage reserva espaço de rolagem para os últimos widgets ficarem acessíveis, mesmo se a faixa de status do Basic estiver desligada.
- A barra de formatação no topo respeita a área segura da tela e o cabeçalho nativo.

## English

The mobile status row is separate from the floating navigation pill. The homepage reserves scrolling space for its last widgets even with Basic's status row off. The top formatting toolbar clears the native header and system safe area. Requires Obsidian 1.11.4 or newer.
