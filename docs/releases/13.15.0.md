# Basic 13.15.0 — Ferramentas Básicas e operações confiáveis

Requer Obsidian **1.11.4+**. O [PR #152](https://github.com/AlanDarfin/Basic-AI-Tools-For-Writers/pull/152) foi revisado e incorporado, com correções adicionais de tradução, configurações e leitura rápida. As preferências existentes e os interruptores dos módulos são preservados.

## Português

- O painel se chama **Ferramentas Básicas** em português e **Basic Tools** em inglês.
- **Tradução** ganhou DeepL Free/Pro, Google Tradutor por Google Cloud Translation, Microsoft Translator e LibreTranslate, além das conexões de IA existentes. Os tradutores dedicados têm configuração e teste próprios. Traduza texto, seleção ou uma cópia Markdown e inverta os idiomas com um toque quando a origem é explícita.
- **Chat** mostra o provedor e modelo ativos, oferece atalhos editáveis de reescrita, resumo e ideias e pode descartar uma resposta pendente sem perder o rascunho. A IA sinaliza respostas bloqueadas ou truncadas em vez de apresentá-las como completas.
- A tradução dedicada preserva também atributos HTML com aspas ou várias linhas, trechos de código em linha com quebra de linha, referências de rodapé e delimitadores escapados quando a proteção de Markdown está ativa. O original permanece intacto; a tradução do arquivo cria uma cópia separada. Não há fallback automático para outro serviço.
- A busca das configurações encontra a chave de tradução, o endereço do LibreTranslate, a região do Azure e o teste de exemplo, em português e inglês.
- O botão de inverter idiomas tem área de toque de 44 × 44 px no CSS mobile, sem aumentar o painel além da tela.
- **Perfis de escrita** restauram os campos alterados se a gravação falhar, mantêm a opção de desfazer e evitam aplicações simultâneas. O **Quick start** fecha ao descarregar o Basic e não redesenha a interface após uma gravação pendente.
- A leitura rápida do mobile respeita **Parar**, desativação, descarregamento, nova leitura e mudanças de nota, provedor ou voz. Desligar o filtro ou o gerenciador do explorador restaura os arquivos ocultos pelo filtro, preservando a consulta para a próxima ativação.

## English

Requires Obsidian **1.11.4+**. Reviewed PR #152 is included with additional translation, settings and quick-read fixes. Existing preferences and module switches are retained.

- The panel is now **Basic Tools** in English and **Ferramentas Básicas** in Portuguese.
- **Translation** supports DeepL Free/Pro, Google Cloud Translation, Microsoft Translator and LibreTranslate in addition to existing AI connections. Dedicated translators have their own settings and sample test. Translate pasted or selected text and separate Markdown copies, and swap explicitly selected languages.
- **Chat** shows the active provider and model, offers editable rewrite, summary and brainstorming prompts, and can discard a pending response while keeping the draft. Blocked and truncated responses are reported instead of being shown as complete.
- Dedicated translation also preserves quoted/multiline HTML attributes, multiline inline code, footnote references and escaped delimiters when Markdown protection is enabled. The original remains unchanged; file translation creates a separate copy. There is no automatic fallback to another service.
- Settings search finds translation credentials, the LibreTranslate address, Azure region and sample test in English and Portuguese.
- The language-swap button has a 44 × 44 px touch target in mobile CSS without widening the panel beyond the viewport.
- **Writing profiles** roll back changed fields when saving fails, retain undo and avoid concurrent applications. **Quick start** closes during unload and cannot redraw the interface after a pending save finishes.
- Mobile quick read respects **Stop**, disable, unload, newer reads and note/provider/voice changes. Disabling the Explorer filter or manager restores files hidden by that filter and keeps the query for reactivation.
