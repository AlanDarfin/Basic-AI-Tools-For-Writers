# Basic 13.2.0 — Fluxos de escrita e preservação de manuscritos

Esta versão reúne as melhorias de configuração, dicionário, tradução e revisão do PR #127 com correções encontradas em uma nova auditoria de edição e persistência. Requer Obsidian 1.11.4 ou superior.

## Ferramentas principais

- A página **Geral** mostra a configuração das ferramentas e abre a seção correspondente; a lista de módulos pode ser filtrada.
- O **Dicionário** pesquisa primeiro nas entradas Markdown locais. Consultar IA e salvar uma definição são ações separadas, com verificação de duplicatas na gravação.
- A **Tradução** usa o texto atual do editor, preserva os elementos Markdown reconhecidos e valida os marcadores antes de criar uma cópia. Links com parênteses e código inline recebem proteção; cancelar descarta a resposta pendente.
- O **Assistente** recupera rascunhos após falhas e ignora respostas de conversas que foram limpas. A revisão verifica a nota de destino mesmo em painéis divididos.

## Correções da auditoria

- A edição de blocos identifica a seção correta entre blocos iguais, rejeita conteúdo desatualizado e mantém uma cerca externa válida quando o conteúdo inclui cercas Markdown.
- A análise de repetições reconhece acentos Unicode compostos ou decompostos. O beat-sheet preserva aliases de wikilinks ao separar título e conteúdo.
- O **Longform** mantém como rascunho o texto digitado enquanto um salvamento está em andamento.
- **Snapshots** concorrentes preservam todas as entradas do índice. Renomear uma pasta mantém a associação dos históricos, comentários editoriais e rascunhos dos capítulos.
- O **Workbench** ignora corretamente tarefas em exemplos com cercas de tamanhos diferentes, sem oferecer a marcação de tarefas dentro desses exemplos.

A [auditoria e as próximas prioridades](https://github.com/AlanDarfin/Basic-AI-Tools-For-Writers/blob/main/docs/AUDIT_V13_2.pt-BR.md) registram o escopo e as lacunas restantes. As verificações automatizadas usam cofres e serviços simulados; respostas reais dos provedores, interação Android e compatibilidade visual com temas precisam de validação no aplicativo.

Validação: **121 arquivos de regressão** e lint CSS aprovados. Um cofre isolado no **Obsidian 1.15.0/Linux** também confirmou carregamento, edição dos blocos, repetições Unicode e snapshots simultâneos.

Instale os três anexos oficiais na pasta do Basic: `main.js`, `manifest.json` e `styles.css`. O ZIP e os checksums ficam nos artefatos do workflow de publicação.

## English

Basic 13.2.0 includes first-use configuration, local Markdown dictionary lookup, protected note translation, chat draft recovery and split-pane review from PR #127. This audit also fixes adjacent identical block editing, nested Markdown fences, Unicode repetition analysis, beat-sheet wikilinks, edits made during Longform saves, concurrent snapshot indexing, folder rename continuity and task detection inside fenced code. Requires Obsidian 1.11.4+. Automated checks use simulated vaults and services; Android, provider responses and theme compatibility still require application testing.
