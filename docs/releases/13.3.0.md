# Basic 13.3.0 — Spaces e abas no celular

Esta atualização melhora a navegação entre Spaces e painéis no layout móvel. Requer Obsidian 1.11.4 ou superior.

## Spaces acessíveis em mais lugares

- O seletor persistente de Spaces funciona com as **abas nativas**, mesmo sem ativar o gerenciador lateral do Basic. A preferência para desativar essa integração continua disponível.
- A lista tem **busca por nome com tolerância a acentos**, indicação do Space ativo e opção **Todo o cofre**. O seletor pode ser dispensado ao tocar fora ou pressionar Escape.
- **Escolher Space** está disponível nas ações rápidas do Basic e na paleta de comandos, sem precisar navegar até o Explorador.
- Trocas rápidas de Space são processadas na ordem correta, preservando a associação dos layouts. Abrir o painel de coleções não seleciona outra Space automaticamente.

## Detecção de abas

- Painéis repetidos do mesmo tipo e notas Markdown laterais mantêm botões separados.
- O Basic usa os nomes e ícones fornecidos pelos próprios painéis, inclusive de plugins externos.
- A lista acompanha abertura, fechamento, substituição e seleção de painéis. O menu de ações consulta o painel atual, preservando os botões durante atualizações normais.
- Fechar ou manter pressionada uma aba atua na instância escolhida. Preferências existentes de ordem e fixação continuam por tipo de painel.

## Outras melhorias

- A leitura pelas ações rápidas usa o texto atual do editor, incluindo alterações ainda não salvas.
- Abrir um PDF ou outro documento não reutiliza a seleção de uma nota Markdown anterior para formatação; uma leitura pendente é descartada se a nota de destino mudar.

Os arquivos oficiais são `main.js`, `manifest.json` e `styles.css`. As verificações de layout móvel no Obsidian para Linux usam emulação; elas não equivalem a testes em um aparelho Android ou iOS.

## Validação

- Build, sincronização dos arquivos gerados, sintaxe e **125 arquivos de regressão** aprovados; quatro arquivos novos acrescentam **35 casos comportamentais**.
- Lint CSS com três casos aprovados, versões e documentação sincronizadas e integridade do pacote de três arquivos verificada.
- No **Obsidian 1.15.0/Linux com emulação móvel**, foram conferidos o seletor com abas nativas e gerenciador desligado, busca sem acentos, fechamento por Escape/toque fora, retorno a Todo o cofre e identificação de painéis repetidos e Markdown.
- O controle de alterações do drawer também foi verificado em DOM real: desativar o gerenciador ou perder temporariamente o seletor nativo não deixa ciclos de atualização ativos.

## English

Basic 13.3.0 makes the mobile Spaces selector independent of the optional sidebar manager, adds Space search and a quick-action/command chooser, preserves scope when opening collections, and serializes rapid Space layout switches. Sidebar discovery retains duplicate views and Markdown notes, uses real panel titles/icons, tracks changing leaves and resolves actions from the active panel. Mobile read-aloud uses the current editor buffer and avoids stale document selections. Mobile runtime checks use Obsidian desktop emulation; physical Android/iOS validation remains separate.
