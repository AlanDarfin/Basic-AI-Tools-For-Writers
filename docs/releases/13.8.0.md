# Basic 13.8.0 — Plugins conectados e compatibilidade móvel

Requer **Obsidian 1.11.4+**. Plugins externos podem exigir versões mais novas. Esta versão cria conexões específicas com nove plugins após consultar seus fontes originais, preservando configurações e módulos independentes.

## Integrações

- **Plugins conectados** reúne ações disponíveis, painéis nativos reutilizáveis e atalhos para as configurações originais. Escolha lateral direita/esquerda ou nova aba, desligue conexões individualmente e mantenha as preferências salvas.
- **Ultimate Toolkit:** provedor de voz explícito, usando o próprio player e as próprias vozes; Basic continua como padrão. Voz online do Toolkit exige uma permissão separada, inicialmente desligada. O motor online da versão auditada usa Google Translate, apesar do rótulo Edge no original.
- **Visual Kit:** comandos nativos de imagens/anotações e notas HTML; configuração pelo gravador original, preservando o índice. Exclusivo do computador, com recarregamento quando necessário.
- **Snailkit:** aba de escrita do Basic no Workbench pela API pública de tarefas, prévias e conclusão explícita com verificação da linha atual. Desligar a conexão libera a aba e os vínculos.
- **dropit:** recebimento/envio sob demanda, preservando pareamento e regras originais; processamento permanece explícito e restrito ao computador.
- **Syncthing, Git e FIT:** comandos exatos e estado nativo disponível; ações remotas dependem do provedor manual selecionado. Selecionar não sincroniza nem suspende rotinas externas. Git no celular exige o backend próprio disponível e inicializado. Syncthing Integration oferece janelas de conflitos/diferenças/configuração, sem um motor próprio de sincronização.
- **LanguageTool:** o corretor externo usa o editor correto e seus próprios sublinhados, avisos, conta e endereço. Idioma, modo rigoroso, aviso de análise longa e verificação automática podem ser configurados pela conexão. O corretor integrado do Basic continua independente. Desligar a conexão não desliga a verificação automática do plugin externo.

## Mobile e explorador

O posicionamento de controles suportados do Toolkit e do Snailkit considera a área visível, barras, outros controles e o painel dono, acompanhando mudanças de janela/teclado. A organização pode ser desligada e restaura os estilos anteriores. A conexão com o LanguageTool melhora os limites dos seus avisos e áreas de toque no celular.

A prioridade de ícones do explorador permite escolher Toolkit, Basic ou ambos quando há decoração duplicada, preservando as preferências dos dois plugins. O Visual Kit permanece indisponível no mobile. A integração não adiciona o Git do computador ao Android.

## English

Basic 13.8.0 requires Obsidian 1.11.4 or newer; external plugins can require newer hosts. The new **Connected plugins** center uses audited native commands, settings and registered panels from Ultimate Toolkit, Visual Kit, Snailkit, dropit, Syncthing Integration, Syncthing Manager, Obsidian Git, FIT and LanguageTool. Bridges can be disabled individually; existing data and preferences remain intact. Panels reuse existing leaves and open in the chosen sidebar or a new tab.

**Basic remains the default speech provider.** Explicitly choosing Toolkit uses its own player/voices. Toolkit online speech requires an additional permission, initially off; the audited engine sends text to Google Translate despite its Edge label. Native preferences use each plugin's own persistence method. Snailkit gains a Basic writing tab through its public Tasks API and explicit task completion with concurrent-line checks. dropit send/receive/desktop processing remain explicit. Manual sync selection does not transfer data or disable other plugins' automatic work; Git mobile operations depend on its initialized backend. Visual Kit remains desktop-only.

The external **LanguageTool** checker restores the appropriate Markdown editor and owns its underlines/notices, account, endpoint and note overrides. The bridge offers selected native settings; Basic's built-in checker stays independent. External automatic checking can continue when Basic is closed or the bridge is disabled. Mobile tooltip/touch adjustments complement reversible Toolkit/Snailkit control positioning and explorer icon priority.

Reviewed PRs **#136/#137/#138** add visual-only per-draft Longform arc dividers and stable en/em dashes, immediate/Space-triggered replacements and Backspace restoration. Integration fixes preserve the original draft in open prompts, reanchor after chapter edits only after successful native writes, and leave active IME/multi-cursor operations native. Explicitly saved preferences remain intact. The homepage title/icon group is centered on desktop and stacked in narrow/mobile panes, with long-title and custom-image support.

Native Obsidian 1.15.0/Linux keyboard checks confirmed en/em dashes and Backspace restoration. Divider creation, captions, variant independence, pickup movement and manuscript export were exercised using synthetic chapters; exported Markdown excluded divider captions and the Longform index stayed unchanged. At 412×915, divider controls measured 44 px with no overflow. Homepage measurements after restarting with the rebuilt stylesheet covered desktop, narrow/mobile and tablet widths, centered SVG/local-image slots and a long unbroken title. Screenshots are linked above.

The [English guide](https://github.com/AlanDarfin/Basic-AI-Tools-For-Writers/blob/13.8.0/docs/guides/companion-compatibility.md) and source audit document setup, data use, pinned sources and limitations. New regressions use synthetic notes and plugin instances; mobile Electron emulation does not establish physical Android/iOS compatibility or live remote service availability. Install only `main.js`, `manifest.json` and `styles.css`.
