# Basic 13.9.1 — Tarefas confiáveis, cancelamento de voz e página inicial

Requer **Obsidian 1.11.4+**. Esta atualização corrige operações pendentes e resultados incompletos, preservando notas, preferências e os interruptores dos recursos.

## Tarefas e cobertura da busca

Checkboxes dentro de propriedades YAML, comentários HTML/Obsidian e blocos de código não entram no painel como tarefas. Exemplos de marcadores de comentário em trechos de código na mesma linha não escondem tarefas posteriores. Antes de marcar uma tarefa e dentro da gravação atômica, o Basic confere se a linha ainda é uma tarefa elegível e se o arquivo continua igual. Linhas, Unicode e finais de linha existentes são preservados.

O resumo informa notas examinadas/total. **Busca incompleta** avisa quando há notas fora do limite configurado, falhas de leitura ou arquivos com mais de 250 tarefas válidas. **Opções de busca** abre a configuração existente de **Tarefas e captura**; o limite não é aumentado automaticamente. Se uma atualização falhar, os resultados anteriores permanecem identificados por um aviso.

## Leitura em voz alta

Uma leitura de nota ainda pendente deixa de poder iniciar áudio após **Parar**, desativação da leitura, mudança de nota, provedor ou preferências, descarregamento do plugin ou uma solicitação mais recente. A leitura local de nota usa o texto atual do editor quando disponível. Respostas e falhas antigas não substituem o estado de uma leitura nova. As permissões de voz online e a escolha explícita do provedor continuam valendo.

## Interface e suporte

- Callbacks atrasados da barra de formatação não recriam a interface após desligar o Basic.
- O índice de busca mantém todas as opções de voz mesmo quando callbacks usam o mesmo identificador da seção de configurações.
- Ao restaurar a posição de um botão de tarefas com leque aberto do Snailkit, o Basic solicita um único redesenho nativo quando a posição mudou, mantendo a âncora correta.
- O [PR #141](https://github.com/AlanDarfin/Basic-AI-Tools-For-Writers/pull/141) foi revisado e incorporado: título e logo da página inicial ganham destaque no computador e no mobile, mantendo centralização, quebra de títulos longos e imagens personalizadas.

O suporte continua documentado nos READMEs; a página de Integrações permanece removida das configurações. Não há novo serviço remoto nem código dos plugins originais incorporado ao pacote.

Passaram os **161 arquivos de testes**, a geração do pacote e a verificação de CSS da comunidade. O pacote final foi conferido no **Obsidian 1.15.1**: tarefas ocultas, gravação do checkbox, avisos de busca em inglês/português, interruptores dos módulos, cancelamento de voz e barra após descarregamento. A página inicial foi verificada em cinco tamanhos de viewport, com título longo, imagem personalizada e fonte ampliada a 200%, sem transbordamento horizontal.

## English

Basic 13.9.1 requires Obsidian 1.11.4 or newer. The update preserves existing notes, preferences and feature switches.

Task scans exclude checkbox lines inside YAML properties, HTML/Obsidian comments and code fences. Same-line code examples containing comment markers do not hide later tasks. Checkbox writes revalidate task eligibility and the unchanged source before and during atomic processing, retaining existing lines, Unicode and line endings.

The dashboard reports examined/total notes. **Incomplete search** identifies notes outside the configured limit, read failures and files exceeding 250 valid task lines. **Search options** opens the existing task settings without increasing limits automatically. A failed refresh retains earlier results with a warning.

Pending note reads cannot start speech after Stop, disable, note/provider/preference changes, unload or a newer request. Local note speech uses the current editor buffer when available. Stale responses and errors cannot overwrite a newer reading; online permissions and explicit provider selection remain intact.

Late formatting-toolbar callbacks remain inactive after unload. The settings search index retains every speech option even when callbacks mention the same section ID as the settings panel. Restoring a moved Snailkit task button with its fan open requests one native redraw to keep the anchor aligned. Reviewed **PR #141** gives the homepage title and logo more prominence while preserving centering, narrow layouts, custom images and long-title wrapping. The Integrations settings page stays removed; support remains documented in both READMEs. No new remote service or original companion implementation is bundled.

All **161 test files**, package generation and community CSS checks passed. The final package was checked in **Obsidian 1.15.1** for hidden tasks, checkbox writes, English/Portuguese scan warnings, module switches, speech cancellation and toolbar unload. The homepage passed five viewport sizes, a long title, a custom image and 200% text scaling without horizontal overflow. See the [reliability results](../maintenance/13.9.1-reliability-qa.json), [homepage results](../maintenance/13.9.1-homepage-qa.json), [desktop screenshot](../images/13.9.1/homepage-desktop.png) and [mobile viewport screenshot](../images/13.9.1/homepage-mobile.png).

No physical Android/iOS device was tested. Speech checks used audio/network boundary stubs to verify scheduling and cancellation; they do not establish audible speech or live service availability. Replace all three install files together and reload Obsidian.
