# Basic 14.2.0 — Capitulares e exportação fiel

## Português

### Capitular de livro
A primeira letra de um parágrafo pode ocupar várias linhas, como nos romances impressos. Adicione `{dropcap}` ou `{capitular}` ao final do texto. Os atributos podem ser combinados com os alinhamentos do Basic, em qualquer ordem:

```md
Era uma vez uma cidade entre montanhas... {j} {dropcap}
Amanheceu na vila. {capitular} {l}
# Capítulo um {c}
```

A capitular funciona no modo de leitura e ganha realce de edição no Live Preview. Há um comando de paleta e um botão de formatação para alterná-la. O tamanho se adapta ao mobile.

### Compatibilidade de exportação
- **HTML:** o Pandoc recebe um bloco semântico e o HTML autossuficiente inclui estilos para capitulares, alinhamento, sublinhado, spoiler, destaque e cores do Basic.
- **EPUB:** classes semânticas e folha CSS incorporada ao arquivo.
- **DOCX, ODT, PDF, LaTeX:** o texto e a estrutura continuam no documento gerado; uma capitular tipográfica com o mesmo tamanho e posição pode exigir um modelo ou mecanismo de exportação específico.
- **Texto simples:** a estrutura de saída é simplificada pelo Pandoc, sem garantir efeitos visuais.
- **Markdown original:** não é alterado durante a exportação. Trechos de código, frontmatter YAML e listas mantêm a sintaxe original.

As formatações comuns em Markdown (ênfase, negrito, links, listas, imagens) continuam com o Pandoc. As marcações estendidas do Basic são convertidas em atributos Pandoc onde suportadas. Blocos interativos permanecem específicos do Obsidian e não se tornam widgets funcionais no HTML ou EPUB exportado.

A exportação requer Pandoc no desktop e, para PDF, um mecanismo compatível. O ajuste `Justificar e hifenizar parágrafos` continua separado, podendo ser desativado em **Alinhamento de texto e títulos**.

## English

### Book-style drop caps
Append `{dropcap}` or `{capitular}` to an ordinary prose paragraph. Combine it with `{l}`, `{c}`, `{r}` and `{j}` in either order. Reading mode displays the decorative first letter, Live Preview displays an enlarged initial, and the formatting toolbar and command palette can toggle the attribute.

### Export compatibility
- **HTML:** a standalone document receives embedded typography CSS for drop caps, alignment, underline, spoilers, highlights and colors.
- **EPUB:** Pandoc receives semantic fenced divs and embeds the export stylesheet.
- **DOCX, ODT, PDF and LaTeX:** semantic structure and words remain, but matching decorative styling may require output-specific templates.
- **Plain text:** the format has no decorative styling.
- **Safety:** source notes are untouched; fenced code, YAML and list structure are not rewritten.

Native Markdown formatting continues to be handled by Pandoc. Obsidian-only interactive writing blocks are not exported as functioning widgets.
