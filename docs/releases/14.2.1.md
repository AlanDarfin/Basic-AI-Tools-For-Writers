# Basic 14.2.1: Longform compacto no Android

## Português

Esta atualização corrige o excesso de altura das linhas na aba **Escrita > Cenas** do Basic no Obsidian mobile.

- Alça de movimentação, título e botão de mais ações alinhados na mesma linha, inclusive em painéis estreitos.
- Títulos grandes são abreviados com reticências sem prejudicar a abertura da cena.
- Botões de arrastar, abrir, expandir e acessar ações preservam áreas de toque de 44 px.
- Os comandos para mover cenas continuam no menu **Mais ações**.
- Sem alterações no comportamento das cenas no desktop ou nos separadores de arco.
- Cobertura de regressão para estrutura, layout mobile e sincronização de CSS.

## English

Fix oversized Longform scene rows on Android. Drag handle, scene title and overflow menu now share a single compact row, including inside narrow sidebars. Long titles ellipsize while accessible 44px touch controls and the scene menu remain available. Desktop layout is unchanged.

## Installation

Replace all three plugin files from this release: `main.js`, `manifest.json` and `styles.css`. Reload Obsidian or disable and re-enable Basic to apply the updated stylesheet.
