# Basic 15.2.0 — Timeline e blocos Markdown / Timeline and Markdown blocks

## Português

- Timeline narrativa com layout clássico, quebra natural de texto e rolagem responsiva; preserva listas, código cercado e intervalos de anos.
- Chats longos carregados em lotes; blocos com Markdown aninhado preservado.
