# Basic AI Tool for Writers 9.4.1 — Final maintenance before v10

This is a maintenance release focused on the native explorer and inline Markdown note titles. It keeps the features already shipped in 9.4.0 and prepares the migration to the redesigned v10 settings.

## Fixed
- Decorative note icons sit closer to the visual center of the first line of a title (desktop and Android) while remaining non-editable.
- File/folder icons in the native explorer receive matching optical alignment.
- Ellipses for truncated Folder Note descriptions and regular note excerpts render inline after the visible text rather than floating at the far right.
- Removed overly broad coverage in an old desktop compactness test; added regression coverage for aligned icons and inline preview ellipses.

## Previously shipped in 9.4.0
- Fictional chat blocks: simulated voice note bubbles like `[audio:0:15]`, multiline content, visual density, bubble style, width and avatar options.
- Spaces, native explorer controls, Flow, Flexplorer, Pretty-inspired properties, Soundscapes, calendar, LanguageTool and optional TTS.

## Known limits and verification
- Advanced Custom Sorting `sorting-spec` grammar is only partially supported, rather than fully equivalent to the external plugin.
- Pomodoro's advanced task-tracking functions from the upstream project have not been fully incorporated.
- Calendar features operate on local Markdown schedules; Google Calendar/CalDAV synchronization is not claimed.
- Visual behavior on particular Android versions and third-party Obsidian themes should be verified in-app.

Minimum Obsidian version: 1.11.4. Desktop and Android are supported. Install `main.js`, `manifest.json` and `styles.css` together.
