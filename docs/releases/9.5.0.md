# Basic AI Tool for Writers 9.5.0 — Narrative timelines and native Properties

## Fixed
- The optional frontmatter property filter now lives in the same collapsible region as the native property rows. Hiding Properties also hides the search in Live Preview and Reading View.
- Preserve an entered filter while the metadata decoration refreshes.

## New Markdown Timeline blocks
- Original `timeline` three-plus event format, including line/body preset classes.
- Original `timeline-labeled` date/title/content format with multiline Markdown.
- Vertical and horizontal layouts; classic, cards, minimal, compact and editorial themes.
- Event photos from the local vault, internal note buttons, Lucide event icons, custom hex colors, tracks/groups, date text/eras, source or numeric/date sorting.
- Optional toolbar for search, group filtering, orientation switching and scrolling. Accessible buttons and mobile-aware layout.
- `writer-timeline` alias, palette insertion command and independent module switch.
- Existing Longform timeline, fictional calendar, branch filters, milestone and Gantt views are preserved.

## Documentation and compatibility
- Updated English and Brazilian Portuguese READMEs and copy-ready Markdown block guides.
- Source and bundled assets rebuilt and checked through GitHub Actions.
- No upstream plugin source, assets or CSS are copied. Based on the documented syntax of George-debug/obsidian-timeline, MIT.
- Requires Obsidian 1.11.4+; supported desktop and mobile. The Timeline blocks use only vault-local images and linked notes.
- Rendering may differ under third-party themes; visual Android testing is advised.

Install all three attached files — `main.js`, `manifest.json`, `styles.css` — in your plugin directory.
