# Basic AI Tool for Writers 9.5.1 — Fictional chat polish

A focused follow-up to 9.5.0, bringing the missing fictional-chat decorations requested before v10.

## New in the `chat` and `writer-chat` blocks

- `---` on a line of its own renders a subtle divider **between** message bubbles.
- `--- Two hours later ---`, `--- 14:30 ---` and other captioned markers render a centered, theme-aware separator between two rules.
- Dividers reset consecutive-speaker grouping, so a later message can show its speaker name and avatar again.
- `group-image: [[Images/group.webp]]` renders a round **group conversation photo beside the chat title**. Aliases: `group-photo:`, `group-avatar:`, `title-image:`, and `chat-image:`.
- Group images resolve only to local vault images. Existing per-character avatars, profile colors, fake voice notes, multiline Markdown and message-side syntax are preserved.
- The original legacy `=== Speaker` layout continues to use the first bare `---` to separate its header from the message body; subsequent markers may divide the transcript.

## Maintenance

- Responsive, isolated styles for desktop and Android; no modifications to other Markdown renderers.
- New regression coverage for group photos, both divider types, text paragraphs and legacy message syntax.
- Copy-ready English and Portuguese examples in `docs/BLOCKS.en.md` and `docs/BLOCKS.pt-BR.md`.
- Tested with the complete repository check suite and community CSS lint.

Obsidian 1.11.4 or later. Install all three release assets together: `main.js`, `manifest.json`, and `styles.css`.
