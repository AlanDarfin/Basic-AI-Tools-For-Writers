# Basic AI Tool for Writers 9.5.2 — Fictional voice note transcripts

The fictional `chat` Markdown block can now show an optional written transcript beneath a simulated voice note.

## Added
- Accept `[áudio:0:15:Essa é a transcrição.]`, `[audio:0:15:Text]` and `[voice:0:15:Text]`.
- A **Ver transcrição / View transcript** button toggles an accessible plain-text transcript under the animated fake waveform.
- Colons and escaped newline sequences (`\\n`) are supported in authored transcripts.
- The transcript is not shown by default; the toggle has accessible expanded state and region association.
- No speech-to-text, microphone access, media playback, remote requests, or AI calls. Text must be supplied by the person writing the note.
- Existing untranscribed voice notes and all 9.5.1 chat features (separators, group photo, avatars, Markdown, timestamps) remain unchanged.

## Quality and compatibility
- New parser, limits, content-safety and transcript-toggle regression tests, included in the complete test suite.
- New localized styles for desktop and Android with text wrapping and hidden-state handling.
- Updated README and full block examples in English and Brazilian Portuguese.
- Minimum supported Obsidian version: 1.11.4. Desktop and Android.
